# Контент сайта Auguria

Тексты продуктов живут в Markdown. Страница `/products` собирается из этих файлов.

## Продукты

`src/content/products/*.md`

Каждый файл:

```yaml
---
title: "Название"
slug: "url-anchor"
category: "socio" | "political"
order: 5
description: "Короткое описание для карточек"
image: "/assets/city.jpg"
---
```

Секции (можно добавлять и убирать):

- Проблема
- Что это за продукт
- Как это реализуется (технологии)
- Порядок реализации
- Ресурсы
- Сроки
- Что получает заказчик
- Кому подходит
- FAQ

Чтобы добавить продукт: скопируйте любой файл, смените `slug` / `order` / тексты. Якорь страницы = `slug`.
